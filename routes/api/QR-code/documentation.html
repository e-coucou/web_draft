/vCard? [Carte de Visite]

Root commande : /api/qrcode/vcard?
  • Liste des commandes qui doivent être séparées par &. (ex: cmd1=param1&cmd2=param2)

      Identification du Titulaire de la Carte de Visite [vCard]
    • <nom=> NOM [encodage FN:John DOE et N:DOE;John;;M.; ex nom=DOE
    • <prenom=> PRENOM [encodage FN:John DOE ex prenom=John]
    • <genre=> GENRE tout est possible : M., Mme, Mr, Dr, ... [encodage N:DOE;John;;M.; ex genre=M.]
    • <email=> X [encodage N:DOE;John;;M.; ex x=x]
    • <mobile=> X [encodage N:DOE;John;;M.; ex x=x]
    • <fonction=> X [encodage N:DOE;John;;M.; ex x=x]
    • <organisation=> X [encodage N:DOE;John;;M.; ex x=x]

      • L'adresse physique
    • <site=> X [encodage N:DOE;John;;M.; ex x=x]
    • <adresse=> X [encodage N:DOE;John;;M.; ex x=x]

      • Les élements de configuration du QR-Code
    • <QUAL=> X [encodage N:DOE;John;;M.; ex x=x]
    • <COLOR=> X [encodage N:DOE;John;;M.; ex x=x]
    • <LEVEL=> X [encodage N:DOE;John;;M.; ex x=x]
    • <PIXEL=> X [encodage N:DOE;John;;M.; ex x=x]
    • <CONTRASTE=> X [encodage N:DOE;John;;M.; ex x=x]
    • <STANDARD=> X [encodage N:DOE;John;;M.; ex x=x]

  • Example de Fichier
      BEGIN:VCARD
      VERSION:4.0
      FN:John DOE
      N:DOE;John;;M.;
      END
