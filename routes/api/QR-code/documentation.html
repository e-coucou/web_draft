QR-Code Documentation

/vCard? [Carte de Visite]

Root commande : /api/qrcode/vcard?
  • Liste des commandes qui doivent être séparées par &. (ex: cmd1=param1&cmd2=param2)

      Identification du Titulaire de la Carte de Visite [vCard]
    • <nom=> NOM [encodage FN:John DOE et N:DOE;John;;M.; ex nom=DOE
    • <prenom=> PRENOM [encodage FN:John DOE ex prenom=John]
    • <genre=> GENRE tout est possible : M., Mme, Mr, Dr, ... [encodage N:DOE;John;;M.; ex genre=M.]
    • <email=> EMAIL Une adresse mail valide [encodage EMAIL;TYPE=INTERNET:john.doe@domain.net ex email=john.doe@domain.net]
    • <mobile=> X [encodage N:DOE;John;;M.; ex x=x]
    • <fonction=> X [encodage N:DOE;John;;M.; ex x=x]
    • <organisation=> X [encodage N:DOE;John;;M.; ex x=x]
    • <www=> WEB adresse WWW de votre site internet [encodage ; ex www=]

      • L'adresse physique
    • <site=> X [encodage N:DOE;John;;M.; ex x=x]
    • <adresse=> X [encodage N:DOE;John;;M.; ex x=x]

      • Les élements de configuration du QR-Code
    • <QUAL=> QUALITE permet de définir la performance de l'algorithlme de recouvrement : L=7%, M=15%, Q=25%, H=30%
    • <COLOR=> COULEUR La couleur du QR-Code en codage #rrggbb [ex COLOR=#235467]
    • <LEVEL=> NIVEAU Il existe 8 niveaux de codage [0..7] qui permet d'avoir un codage des pixels, vous pouvez choisir le votre ou laisser l'API optimiser en mettant -1 [ ex LEVEL=-1]
    • <PIXEL=> NOMBRE Idéalement entre 6 et 12 mais à vous de choisir, cela représente la largeur de chaque point en pixel [ ex PIXEL=11]
    • <CONTRASTE=> CONTRASTE si=1 il n'y aura pas de variation des points/pixels. En clair on augmente le contraste du QR-Code [ ex CONTRASTE=1]
    • <STANDARD=> STANDARD si=1, les points seront des carrés parfaits, sinon les bodes seront arrondis aléatoirement [ ex STANDARD=0]

  • Example de Fichier
      BEGIN:VCARD
      VERSION:4.0
      FN:John DOE
      N:DOE;John;;M.;
      EMAIL;TYPE=INTERNET:john.doe@domain.net
      END
