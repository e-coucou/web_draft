QR-Code Documentation

/vCard? [Carte de Visite]

Root commande :

/api/qrcode/vcard?
📇 Identification
  • nom = DOE → FN:John DOE
  • prenom = John
  • genre = M. / Mme / Dr
  • email = john.doe@domain.net
  • mobile, fonction, organisation, www → libres
🏠 Adresse physique
  • site → champs libres désigne le lieu
  • adresse → champs libres séparé par de ; rue;ville;code postal
⚙️ Configuration QR-Code
  • QUAL = L / M / Q / H
  • COLOR = #rrggbb
  • LEVEL = 0 à 7 / -1
  • PIXEL = 6 à 12
  • CONTRASTE = 1
  • STANDARD = 1 ou 0
📝 Exemple vCard 
            BEGIN:VCARD
            VERSION:4.0
            FN:John DOE
            N:DOE;John;;M.;
            EMAIL;TYPE=INTERNET:john.doe@domain.net
            END:VCARD
